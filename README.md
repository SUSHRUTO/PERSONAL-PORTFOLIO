# Personal Portfolio Website

A responsive and modern personal portfolio website developed during my **Frontend Web Developer Internship** at **Edunet Foundation (IBM SkillsBuild)**. The website showcases my professional profile, technical skills, projects, certifications, resume, and contact information in a clean and user-friendly interface.

## 📌 Overview

The portfolio is designed to provide recruiters, collaborators, and visitors with a centralized platform to learn about my background, technical expertise, and project experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Professional landing page with introduction
- About Me section
- Technical Skills showcase
- Projects section
- Internship & Education details
- Certifications section
- Resume download option
- Contact section with social media links
- Smooth scrolling navigation
- Interactive animations using JavaScript

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript

No additional dependencies or installation are required.
